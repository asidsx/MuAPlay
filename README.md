## 🌟 Ключевые возможности и функционал плеера

### 🔊 1. Neural DSP Hi-Res Audio Engine & Звуковой процессинг
- **Студийный Lossless звук:** Воспроизведение аудиопотока до **192 kHz / 24-bit / 32-bit Float** без ресемплинга и сжатия.
- **Широкий спектр форматов:**
  - **Lossless & Hi-Res:** `FLAC`, `WAV`, `ALAC`, `AIFF`, `DSF`, `DFF` (DSD Audio), `APE`.
  - **Compressed:** `MP3`, `M4A`, `AAC`, `OGG`, `OPUS`, `WMA`, `WEBA`.
- **Автоматическая нормализация громкости (Smart Loudness Normalizer / ReplayGain):**
  - Непрерывный расчёт воспринимаемой громкости в реальном времени по международному стандарту **EBU R128 (-14 dBFS RMS)**.
  - Устраняет перепады громкости между разными треками и альбомами (тихие акустические записи и громкий мастеринг звучат на едином комфортном уровне).
  - Плавная подстройка усиления (Exponential Moving Average) с защитой от накачки шума в паузах.
- **Студийный пик-лимитер (Brickwall Limiter & Dynamics Compressor):**
  - Аппаратная защита от перегрузок и цифрового клиппинга на выходе аудио-цепи (порог -2.0 dB, сверхбыстрая атака 3 мс).
- **10-полосный студийный эквалайзер:** Точная настройка частот от **32 Гц** (суб-бас) до **16 кГц** (кристальные верха).
- **Sandevistan Bass Boost:** Алгоритмическое усиление суб-баса и гармоник без клиппинга и искажений.
- **Cyber Spatializer (3D стереобаза):** Пространственное расширение звуковой сцены для наушников и акустики.
- **Управление панорамой и балансом:** Регулировка баланса стерео (L/R) в реальном времени.
- **Pitch & Speed Control:** Независимое изменение скорости воспроизведения (0.5x – 2.0x) и тональности.
- **Фоновое воспроизведение (MediaSession API):** Управление треками из шторки уведомлений, экрана блокировки Android, виджетов и Bluetooth-гарнитур / умных часов с передачей обложек высокого качества.

---

### 🗂️ 2. Дата-Шарды (Плейлисты) и управление очередью
- **Создание и управление дата-шардами:** Группировка треков по настроению, жанрам и коллекциям.
- **Добавление треков напрямую из медиатеки плеера:**
  - Удобный выбор с вкладками фильтрации: **«Все в плеере»**, **«Ещё не в шарде»** и **«Избранное»**.
  - Быстрый поиск треков по названию, артисту, альбому и формату.
  - Интерактивное **предпрослушивание аудио** прямо в модальном окне перед добавлением.
  - Массовое выделение треков в один клик («Выбрать все»).
- **Автоматическая загрузка очереди воспроизведения:**
  - Запуск трека из плейлиста или кнопки **«Слушать всё»** / **«Перемешать»** автоматически наполняет очередь плеера треками шардированного списка.
- **Интерактивная очередь (Up Next Queue):**
  - Просмотр текущей очереди треков.
  - Drag-and-drop сортировка порядка воспроизведения на лету.
  - Быстрое удаление композиций из очереди и добавление треков в режим «Играть следующим».
- **Экспорт и импорт плейлистов:**
  - Экспорт дата-шардов в универсальный формат `.m3u` / `.m3u8`.
  - Импорт сторонних плейлистов `.m3u8` с автоматическим связыванием локальных треков.
  - Полный экспорт резервной копии всей медиатеки и шардов в формате JSON.

---

### 📜 3. Караоке-движок и синхронизация текстов (LRC Engine)
- **Многоуровневый парсинг метаданных:** Извлечение встроенных слов песен из ID3 (`USLT`/`SYLT`), Vorbis Comments (`LYRICS`), MP4 (`©lyr`).
- **Синхронизированный караоке-режим:**
  - Поддержка таймкодов сотых долей секунд в файлах `.lrc`.
  - Построчная и плавная подсветка текущей строки в реальном времени.
  - **Клик по строке текста** для мгновенной перемотки аудио на нужный момент композиции.
- **Онлайн-поиск текстов:** Автоматическая интеграция с **LRCLIB API** для поиска слов песен при их отсутствии в локальном файле.
- **Поддержка внешних файлов:** Автоподхват файлов `.lrc` и `.txt`, лежащих в одной папке с треком.

---

### 🏷️ 4. Студия метаданных и редактор ID3-тегов
- **Редактирование тегов:** Изменение названий, артиста, альбома, года релиза и жанра трека.
- **Нейро-поиск обложек и метаданных:** Автоматический поиск официальных обложек альбомов высокого разрешения через API Deezer и iTunes Search.
- **Кастомная загрузка обложек:** Установка собственного изображения на трек или плейлист из памяти устройства.
- **Аудио-инспектор:** Детальное отображение параметров контейнера: кодек, битрейт (kbps), частота (kHz), разрядность (bit), размер файла и путь.

---

### 🌌 5. Cyber Visualizer & Интерактивный интерфейс
- **CyberReactiveRing (FFT-визуализатор):** Анимированное неоновое кольцо на базе HTML5 Canvas 2D (60 FPS), реагирующее на низкие, средние и высокие частоты в реальном времени.
- **Энергосбережение (Battery Saver Mode):** Быстрый тап по обложке мгновенно замораживает анимации для экономии аккумулятора.
- **Сенсорные свайп-жесты:**
  - Свайп влево ($\leftarrow$) — следующий трек.
  - Свайп вправо ($\rightarrow$) — предыдущий трек.
  - Свайп вверх ($\uparrow$) — разблокировка кибер-экрана блокировки.
- **Спящий режим (Sleep Timer):** Таймер автоотключения воспроизведения с плавным угасанием звука.

---

### 🔒 6. Cyber Lockscreen (Экран блокировки)
- Полноэкранный кибернетический HUD с часами, датой и индикатором заряда батареи.
- Музыкальный виджет с бегущей строкой текста песни и кнопками быстрого управления.
- Встроенный светодиодный фонарик (Torch) для смартфонов.

---

### 💾 7. 100% Оффлайн хранилище и сканер памяти
- **Локальная БД IndexedDB:** Быстрое сохранение треков, кэшированных обложек и предрассчитанных волнограмм.
- **Умный сканер папок:** Сканирование внутренней памяти и папки «Загрузки» с игнорированием не-аудио файлов.
- **Фильтрация и группировка:** Быстрая сортировка по исполнителям, альбомам, папкам, избранному и качеству (Hi-Res).

## 🚀 Установка и запуск

### Вариант 1: Установка как PWA на Android (Рекомендуется)
1. Откройте приложение в браузере Chrome на вашем смартфоне.
2. Нажмите меню **«•••»** (или значок в адресной строке).
3. Выберите **«Установить приложение»** / **«Добавить на главный экран»**.
4. Запускайте MUAPLAY как полноценное нативное Android-приложение без рамок браузера с поддержкой оффлайн-режима.

### Вариант 2: Сборка и подпись нативного Android APK (Android 14–17)

Проект полностью настроен для сборки релизного APK с поддержкой схем подписи **v1, v2, v3 и v4**, выравниванием `zipalign 4` и совместимостью с **Google Play Protect**:

```bash
# 1. Сборка веб-дистрибутива и синхронизация Capacitor
npm run build
npm run cap:sync

# 2. Автоматическая сборка, выравнивание (zipalign) и подпись (apksigner v1-v4)
npm run apk:sign
```

*Готовый файл появится в `android/app/build/outputs/apk/release/app-release.apk`.*

### Вариант 3: Запуск веб-версии для разработчиков (Node.js)

```bash
# Клонируйте репозиторий
git clone https://github.com/your-username/muaplay-cyber-audio.git

# Перейдите в папку проекта
cd muaplay-cyber-audio

# Установите зависимости
npm install

# Запустите сервер разработки
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

## 🛠️ Технологический стек

- **Core:** React 18, TypeScript, Vite
- **Аудио-движок:** Web Audio API (`AudioContext`, `BiquadFilterNode`, `AnalyserNode`, `StereoPannerNode`, `ConvolverNode`)
- **Графика и анимация:** HTML5 Canvas 2D (60 FPS FFT Spectrum Visualizer), Tailwind CSS, Lucide Icons
- **Хранилище:** IndexedDB (`idb-keyval`), LocalStorage
- **Метаданные:** `music-metadata-browser`, Deezer API, iTunes Search API, LRCLIB API
